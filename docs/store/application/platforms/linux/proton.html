Steam's Proton Support For Windows Games

Valve’s Proton compatibility layer allows Linux users to play the Windows version of the game on Linux. This means that thousands of games that would ordinarily be unplayable on Linux are able to run, and in many cases perform just fine.

But sometimes a Proton bug will result in the game behaving differently on Linux than it does on Windows. When that happens, it is usually a bug in the Proton compatibility layer and we'd like to know about it so that we can improve Proton for all games.

Reporting Proton issues with your game


You can report Proton issues directly to Valve in the proton issue tracker on Github.

The Proton issue tracker has one issue thread per steam appid, so once the thread exists you can continue reporting new bugs under the same thread.
  1. Visit https://github.com/ValveSoftware/Proton/issues/ and search by your game's appID to see if there is already a thread of issues.
  2. If not, click "New Issue" and fill in the form.

Feel free to let your players know that they can report issues directly to your game's issue tracker.
